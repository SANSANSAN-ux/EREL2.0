# ЭРЭЛ — независимая платформа лицея

Новый проект с нуля, не связанный с прежними проектами и репозиториями.

## Запуск на Windows
1. Установи Python 3.11+.
2. Распакуй папку `EREL` в удобное место.
3. Открой папку, введи `cmd` в адресной строке Проводника.
4. Выполни:
   ```
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   copy .env.example .env
   uvicorn app.main:app --reload
   ```
5. Открой http://127.0.0.1:8000

Локально используется SQLite (`erel.db`). Для публичного размещения задай `DATABASE_URL` от PostgreSQL.
Первый администратор создаётся из `ADMIN_EMAIL` и `ADMIN_PASSWORD`.
Регистрация учителя и работника требует `STAFF_INVITE_CODE`.
Не публикуй `.env`. Перед запуском для всего лицея настрой HTTPS, сильные секреты,
резервное копирование, ограничения запросов и согласуй обработку данных с администрацией.
